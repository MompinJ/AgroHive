# A1.2 — Plan de implementación

**Objetivo:** base React + Vite + TypeScript estricta con P0–P3 navegables sin backend.
**Autorización:** plan del usuario aprobado en el chat; incluye infraestructura de `web/`.
**Diseño:** superficies claras, verde profundo, tonos de suelo, controles nativos y tres paneles adaptables. Sin imágenes, fuentes ni servicios remotos.
**Arquitectura:** `App.tsx` conserva exclusivamente selecciones de interfaz; rutas hash permiten recarga y navegación atrás en alojamiento estático. Los componentes viven en `ui/` y las vistas en `paginas/`. No se crean tipos de dominio provisionales.
